# User Project Guidelines

*   **Responsive & Non-breaking**: EVERY component built must be 100% responsive for every device and strictly non-breaking within the existing theme architecture.
*   **Fully Editable**: Everything asked for each component should be fully editable in the Shopify Customizer (via Liquid schema settings and blocks).
*   **Exact Implementation**: Follow the specific visual cues and animations requested (e.g., replicating Airvalent's specific styles and behaviors) precisely.
*   **Targeted Delivery**: ONLY provide the specific Liquid file requested. Delete any generic HTML, CSS, or JS prototypes previously made for this project to keep the repository clean.
*   **Enforcement**: These instructions must be recalled and strictly followed on EVERY prompt moving forward.

*   **STRICT WARNING**: Do NOT change existing JSON templates (like index.json) or overwrite the live theme files from local without explicitly asking or pulling first, as it will wipe out the client's CMS changes.
